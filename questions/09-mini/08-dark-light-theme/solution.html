Theme Demo

Welcome

This page demonstrates a dark/light theme switcher. Toggle the button in the header to switch themes. Your preference is saved and restored on next visit.

Themed Component

How it works

CSS custom properties defined on :root are overridden by the [data-theme="dark"] attribute on the <html> element. JavaScript reads and writes localStorage to persist the choice.

System Preference

On first load (no localStorage entry), the app checks the OS preference via prefers-color-scheme. Changes to the OS preference after page load are also detected — unless the user has set an explicit preference.
